## Phases

### Phase 5 — UI Polish Backlog (mới, từ audit UI 2026-09-16)

- **Task 5.1 — Dashboard scale (pagination/virtualization)**
  - Dashboard hiện render toàn bộ project card trong 1 lần `innerHTML` — đo thật 176
    project card / 358 button, trang cao ~17,000px. Cần pagination hoặc virtual list,
    có thể kèm sort "Recently updated" nếu chưa có.
- **Task 5.2 — Timeline polish (proportional width + keyboard resizer)**
  - Timeline clip width chưa tỷ lệ theo duration thật (đoạn 3s và 7s hiện gần bằng
    nhau) — ảnh hưởng Script/TTS/Video, 3 trang cùng dùng pattern timeline.
  - Horizontal timeline resizer (`#resizer-top`) có `tabindex="0"` nhưng không xử lý
    phím — chỉ resizer dọc (sidebar/inspector) mới có keydown handler trong `shell.js`.
- **Task 5.3 — Small polish batch**
  - Learning card có click handler nhưng không có semantic role/`tabindex` cho bàn
    phím.
  - Learning inspector mặc định trống (340px) thay vì hiển thị item đầu tiên.
  - Video avatar section hiện lộ tính năng chưa dùng được (LivePortrait lip-sync) mà
    không collapse/ẩn — gây cognitive load không cần thiết.
