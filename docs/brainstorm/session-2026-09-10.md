## Features

### Script Generation Config
- CEFR Level: A1/A2/B1/B2/C1/C2
- Duration: 30s-1m (Shorts), 3-5m, 7-10m, 12-15m, 20-30m, custom
- Speakers: 1-6 people
- Content types: Instructions, Directions, Debate, Informational, Interview, Opinion, Storytelling, Daily Conversation, Negotiation, News
- Accent regions: American, British, Australian, Canadian, Irish, Scottish, Indian, Singaporean, NZ, South African
- Language features toggle: Collocation, Idiom, Slang, Local expressions, Phrasal verbs, Fixed phrases, Business/Casual register

### AI Quality Controls (Strict Prompt)
- CEFR vocabulary check
- CEFR grammar check
- Genre-appropriate sentence structure
- Oxford/Cambridge collocation accuracy
- Natural multi-speaker interaction (turn-taking, fillers)
- No repetition, grounded content
- Per-segment re-generate
- Prompt templates per genre

### Learning Content Output
- Full transcript
- Vocabulary list (tiered)
- Collocation & idiom explanations
- Grammar structures
- Timestamps (post-audio)
- Video description
- YouTube tags & keywords
- Comprehension questions
- Key takeaways

### TTS & Audio
- OmniVoice (primary local): 600+ langs, voice design, RTF 0.025
- Edge TTS (free local backup)
- Piper TTS (offline)
- Coqui TTS (OSS)
- Google Cloud TTS + Azure TTS (API optional)
- Auto-mix multi-speaker audio
- Auto silence/pause
- MP3 + WAV export
- Per-segment preview
- Speed/pitch/volume per voice
- Waveform visualization
- User-managed music library (copyright-safe)

### Thumbnail
- AI generation (Gemini Vision)
- A/B versions
- 16:9 (1280x720) + 9:16 Shorts
- Template library
- In-app editor

### Video Studio (Canva-style)
- Background images/templates
- Subtitle overlay
- Layout adjustment
- Export MP4

### YouTube Package
- AI-generated description
- Auto timestamps
- Tags & keywords
- Full transcript + vocab + grammar

### Project Management
- Dashboard
- Step-by-step wizard (6 steps, 1 page each)
- Preview + inline editor
- Auto-save
- Script/project library
- Dark/Light mode
