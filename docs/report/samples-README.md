# Sample episodes for T6 report

3 real sample podcast episodes generated by Daily Intel English Studio, showing the same
topic + genre + speakers at three CEFR levels so the difficulty progression is the clearest
to compare.

**Topic:** "The morning routine of a successful entrepreneur"
**Genre:** interview · 2 speakers (Alex + Maya, American accent)
**Duration:** 5 minutes each
**Generated:** 2026-09-15 (Task 3.2 deliverable)
**Pipeline:** real Gemini script generation + real Edge TTS synthesis + real ffmpeg mix — nothing mocked

## Files per level

Each `A1/`, `B1/`, `C1/` folder contains:

- `script.md` — readable dialogue transcript with speaker names
- `script.json` — machine-readable version (line ids, timing, speaker attribution)
- `audio.mp3` — the mixed episode audio (voice + silence gaps, EBU R128 normalized to -16 LUFS)

## What to notice comparing the 3 levels

- **A1** (starter): simple present tense, short lines, everyday vocabulary. Model dialogue
  a beginner can follow after ~3 months of study.
- **B1** (intermediate): mixed tenses, longer sentences, some idioms, richer vocabulary.
  This is the level Gate B-11 measures at 45s median cloud generation.
- **C1** (advanced): complex sentence structures, hedging language, professional register,
  vocabulary a native speaker uses in a business interview.

The same topic + speakers + genre appear in all three so the reader can isolate the
level's linguistic complexity from any content variation.

## How these were produced

`scripts/generate_sample_episodes.py` calls the app's service layer directly (not the HTTP
API) — the same code path a real Dashboard "Generate" click uses, without inserting rows
into the real `data/app.db`. See the script's docstring for the full architectural
disclosure.
