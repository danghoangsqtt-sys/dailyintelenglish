# Activity Library — locked D72 generic prompt pack

Phase 32.6e. This is the canonical 20-image generic starter pack approved in decision D72.
The five later common activities and the 80 professional verb visuals are valid expansions, but
they are not counted as part of this locked baseline.

## Framing and prompt assembly

For each row, use this complete prompt structure: **standard opening + primary prompt + standard
constraints**. Do not attach an Alex or Lina reference image.

Standard opening:

> Create exactly one new 16:9 landscape 1280x720 image for a full-screen English-learning video
> cutaway.

Standard constraints (the negative prompt):

> Use anonymous people, hands, objects or places only; do not depict Alex, Lina, a celebrity or
> any recognizable recurring character. Clean semi-realistic editorial photo-illustration,
> natural mid-action, subject fully inside the frame, and calm lower-centre space for subtitles.
> No text, captions, readable signs, logo, watermark, brand, UI, collage, split screen, close
> portrait, cropped action, distorted hands, extra fingers or duplicate limbs. Return one image
> only.

## Import and review

Save accepted images under their exact filename in
`data/library/activities_inbox/generic/common/`. In Shot Library, verify the activity and
context, correct aliases if useful, and approve each image once. Pending or rejected images never
enter matching. The expanded copy-ready ChatGPT Web blocks are in
`docs/operations/activity-library-chatgpt-web-generic.md`.
