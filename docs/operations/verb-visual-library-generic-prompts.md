# Verb Visual Library - Generic prompt pack

## Batch 1

This is the approved first batch: **80 generic images**, organised as 10 scenario
families with 8 verb-level actions each. These images extend the existing 25 broad
generic activities; they do not replace them.

## How to use

1. Do **not** attach an Alex or Lina reference image.
2. In ChatGPT Web, copy **one code block only** and generate one image.
3. Download the accepted result as the filename in the heading into
   `data/library/activities_inbox/generic/`.
4. Do not change the scope, activity, context, double underscores, or `01`
   variant. Use `02` only for a distinct approved alternative.
5. After import, add the listed aliases and the scenario-family tag in Shot
   Library before approval. The importer initially reads the activity and the
   filename context only.

All prompts require a normal non-transparent 16:9 landscape image, at least
1280x720. They intentionally use anonymous people or hands only and prohibit
Alex/Lina, text, logos, watermarks, readable signs, readable UI, collage,
split screen, extra limbs, distorted hands, and cropped key action.
