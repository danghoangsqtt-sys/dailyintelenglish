# The 55 scenes: pictures of Alex and Lina to make outside the app (2026-10-07)

Each scene is one place. For every scene the library can use up to four pictures; **start with the first 12 scenes** (they are the
places most stories use), then go on in the order of the table. The name of each file carries its tags, so the app files it by
itself: copy the pictures into the inbox folder and press **Import pictures** on the Shot Library page (`/shots`).

## How to name the files

| Picture | File name (`key` is the first column below) |
|---|---|
| Both people, wide (the whole table or street) | `key__duo-wide.png` |
| Both people, closer | `key__duo-close.png` |
| Lina alone, talking | `key__single-lina.png` |
| Alex alone, talking | `key__single-alex.png` |
| Another action or mood (optional) | `key__duo-wide__drinking-coffee__smile.png` (action, then one of calm, smile, laugh, surprised, thinking, worried, serious) |
| Alex on the left instead of Lina | `key__duo-wide-rev.png`, or name them left to right: `key__duo-wide-alex-lina.png` |

- **Size: 16:9** (for example 1536 x 864 or 1344 x 768). A 4:3 picture is cropped to 16:9 and loses its bottom quarter.
- **Lina on the left, Alex on the right** unless the name says otherwise. They should look at each other, not at the camera.
- **Same clothes every time:** Lina in the white mini dress, Alex in the navy suit, white shirt and black bow tie.
- A **seated** scene needs a seated picture (a table between them); a **standing** scene needs them standing or walking.
- Do not change a face between pictures: a picture is only reused if you approve it, and you approve each one once.
- Inbox folder: `data\library\shots_inbox` (the page shows the full path). Files that cannot be filed stay there with the reason.
