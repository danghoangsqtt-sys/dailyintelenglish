## Use

Click **Daily Beyond English Studio** on the Windows Desktop. The shortcut uses the existing channel logo embedded in the EXE. It starts the local application, opens its browser interface at `http://localhost:8000`, and keeps the backend running without a console window. A second click opens the existing instance. Closing the browser does not stop the backend.

The installed program is `dist/DailyIntelEnglishStudio/DailyIntelEnglishStudio.exe`. Keep the complete `_internal` directory and `studio-runtime.json` beside it. This is the Windows desktop entry point for this repository's existing local runtime: Node/Remotion, ffmpeg, the image environment and models remain installed in the workspace. They are not redownloaded on each click.

`studio-runtime.json` selects the repository two folders above the installed EXE and its `data` directory, independently of the launch working directory. Existing explicit `DIE_WORKSPACE_DIR`/`DIE_DATA_DIR` environment variables take precedence. UI, prompts, fonts, migrations and the logo are bundled; external renderer and image-worker paths use the linked workspace. The current 13-project data is retained. The old AppData database is preserved separately, not merged or overwritten.

Startup diagnostics: `data/logs/desktop.log`. A startup exception displays a native error dialog. The new Windows renderer uses ANGLE for the GPU compositor; see [performance measurements](render-performance-20261015.md).

## Rebuild / install (maintainers)

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_exe.ps1 -OutputRoot data/tmp/desktop-stage
powershell -ExecutionPolicy Bypass -File scripts/install_desktop.ps1 -StageDirectory data/tmp/desktop-stage/DailyIntelEnglishStudio
```

The build script checks failures and writes build metadata plus a runtime locator. The installer stages a complete directory, stops only the EXE at the exact installed path, retains the old distribution under `data/backups/desktop-<timestamp>/`, swaps the new directory into place and creates the branded shortcut. Do not install while an AI/media job is active.
