## Summary
Phase 41 promises to update selected components after every new version. The export plan includes `script.txt` and `learning_pack.txt`, but saving/regenerating a script and generating/editing a learning pack do not call `export_service.sync_quietly`. The files can therefore retain old content until another media action or a manual sync occurs.

## Details
- **Affected files**: `backend/api/projects.py`, `backend/api/learning.py`, `backend/content/script_pipeline.py`, `backend/content/learning_pipeline.py`, `backend/content/export_service.py`
- **Evidence**: `export_service.py:135-186` plans the text files; `rg sync_quietly backend` finds hooks for audio, video, shorts, YouTube, and thumbnail only. Script and learning write paths have no hook.

## Acceptance Criteria
- [x] Update selected script/learning files after successful generation, regeneration, and user edits.
- [x] Add a regression test that edits each component after an initial export and checks the file content without a manual sync.
