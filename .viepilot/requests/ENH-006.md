## Summary
`.viepilot/ARCHITECTURE.md`'s Project data model section documents the `status` field
as an enum (`"draft|script_generated|audio_generated|video_generated|complete"`) but
says nothing about the transition rules. In particular, it does not mention the
real, non-obvious behavior added under Task 7.1 (2026-09-18, fixing BUG-013): editing
a project's script (via generate, regenerate, or manual save) while its status is
already `audio_generated`/`video_generated`/`complete` silently downgrades the
project's status back to `script_generated`, non-destructively. A future reader of
ARCHITECTURE.md relying on the status enum alone would reasonably assume status only
ever moves forward — as it did before Task 7.1 — and would be surprised by this
correct-but-undocumented downgrade behavior.
