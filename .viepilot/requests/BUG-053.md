# BUG: Local image worker failure crashes thumbnail drawing with an unhandled 500

## Meta
- **ID**: BUG-053
- **Type**: Bug
- **Status**: planned (Phase 79)
- **Priority**: high
- **Created**: 2026-10-26
- **Reporter**: vp-audit

## Summary

`POST /thumbnails/topic-picture` and `/thumbnails/ai-scenes` catch only `QwenUnavailable`. Any other image-worker failure (the owner's log shows `OSError ... paging file is too small (os error 1455)` twice) escapes as a RuntimeError: HTTP 500 with a traceback and no readable reason in Step 6.

## Acceptance Criteria

- A worker failure returns a typed error with a plain, actionable message (paging file / GPU memory / generic), details in the log.
- Tests cover both endpoints.
