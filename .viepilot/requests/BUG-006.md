## Summary
The UI requires a topic and trims names, but `ScriptConfig` accepts an empty topic and whitespace-only project/speaker names. Direct API clients can persist invalid projects that later fail or generate poor content.

- **Tier**: 3
- **Audit date**: 2026-09-11

## Resolution
Added validators to `SpeakerConfig`, `ScriptConfig`, and `ProjectUpdate` in `app/models/project.py` that strip surrounding whitespace and reject blank or whitespace-only project names, topics, and speaker names with HTTP 422. Added unit, service, and HTTP API regression tests across `tests/test_projects_api.py` and `tests/test_project_service.py`.
