## Summary

Owner: install the app on a laptop (24 GB RAM, 4 GB VRAM) to test it on a lower-end machine; keep **every current character and the data libraries** so the other machine can start working at once, and **keep the machines in sync**; delete the junk test data, tidy the source folder, and freeze the current version.

Owner choices (2026-10-22): delete all 15 test projects; sync with a **library package** (export / import); version **1.5.0**; hand over by **USB / Drive** (nothing extra published).

## Scope

- **Library package:** one `.zip` with the characters (profiles, approved pictures, sprites, voices), the activity library, scene backgrounds, the music library, the brand voice clips and the channel plan. Import merges by id: new rows are added, a row is replaced only when the package copy is newer (`updated_at`), files are copied when missing or newer; nothing is deleted. API keys and projects are never in the package. The database is backed up before an import. Export and import from Settings → Data & sync, and from a command-line script for large files on USB.
- **Clean-up:** a dry-run-first workspace clean-up — all projects (with their media), `data/tmp`, old app backups (the newest kept), the PyInstaller `build` folder, leftover `dist/*.next-*`, render staging, demo output, stray logs.
- **Release 1.5.0:** CHANGELOG `[1.5.0]`, build version 1.5.0, tag `v1.5.0`, the installed app rebuilt, and a hand-over folder (app ZIP, library package, laptop guide).
