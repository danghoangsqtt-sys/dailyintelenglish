## Summary
The owner wants to replace the heavily limited Gemini free tier with NVIDIA Nemotron, served free
by OpenCode Zen:
- endpoint `https://opencode.ai/zen/v1/chat/completions` (OpenAI-compatible, Bearer key);
- models `nemotron-3-ultra-free` (550B MoE, 55B active) and `nemotron-3.5-lightning-free`
  (30B MoE, 3B active).

This reverses owner decisions D9/D11 (local-only) for the primary path, so it needs an explicit
owner decision when planned.

## PM evaluation (2026-09-23, public docs)
- Usable from our own app: an OpenAI-compatible chat-completions endpoint, and the Zen docs allow
  use outside OpenCode.
- **Limited-time free**, with no published end date. The docs mark both Nemotron models "Trial
  use only — do not submit personal or confidential data" and say data may be used to improve the
  model. Podcast scripts are not confidential; no personal data should go into topics.
- No published rate limits, and no statement about JSON schema / `response_format` support. The
  pipeline depends on strict JSON, so this must be measured.
- Nemotron 3.5 Lightning also runs locally via Ollama. On a 12 GB RTX 3060 it needs RAM offload.

## Proposed design (to be planned after Phase 17)
- One generic `OpenAICompatProvider` (base URL, model, key from `.env`, never committed).
- Router mode: cloud primary, local qwen3.5:9b fallback, so an expired free tier or rate limit
  degrades to local instead of failing.
- An A/B gate on the same protocol: qwen vs Nemotron 3 Ultra vs Nemotron 3.5 Lightning.
- Pace/word-budget calibration re-checked per model.
