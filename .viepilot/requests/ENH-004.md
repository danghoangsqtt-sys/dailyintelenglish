## Summary
`app/db/database.py`'s `Database` class is a process-wide singleton wrapping exactly
one shared `aiosqlite.Connection` (confirmed via direct read: `connect()` opens the
connection once and caches it; `get_db()` always returns the same connection object).
No connection pool exists. No `PRAGMA journal_mode=WAL` is set (grepped the whole
`app/` tree for `journal_mode`/`WAL`/`PRAGMA` — only `PRAGMA foreign_keys = ON` is
present). `aiosqlite` internally serializes all operations against a single connection
through its own background thread, so every DB read and write across every concurrent
request queues behind this one connection.
