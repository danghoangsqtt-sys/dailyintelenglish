## Summary
Smart upload waits synchronously for the entire vision batch before saving images or returning a response. The Ollama request sets `keep_alive=0` on the final item, which means every one-image upload unloads the model and the next one reloads it. A direct Ollama probe using the application's exact request payload on an idle RTX 3060 took 8.26 seconds cold (6.45 seconds model load) versus 1.78 seconds for the next warm image; a second trial took 4.56 seconds cold versus 1.43 seconds warm. These are model-call timings, not full API upload timings. The page shows only `AI is analyzing…`, and server logs do not record per-upload model load, inference, queue wait or total duration, so the owner's longer waits cannot yet be apportioned precisely.
