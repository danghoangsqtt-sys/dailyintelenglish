# ENH: One export subfolder per series episode

## Meta
- **ID**: ENH-035
- **Type**: Enhancement
- **Status**: planned
- **Priority**: high
- **Created**: 2026-10-14
- **Reporter**: owner
- **Source**: `D:\Example-videos\Local Market` holding a series episode's files at its root

## Summary
The project folder (Phase 41) copies fixed names (`video.mp4`, `thumbnail.png`, …) straight into the chosen folder, so
episodes of one series sharing a folder overwrite each other. Owner decision 2026-10-14: the chosen folder is the
**series folder**; each episode gets its own subfolder `Ep 02 - <episode title>`.

## Plan
- `export_service.episode_folder(db, project_id, root)`: for a project in the channel plan, `root / "Ep NN - <title>"`
  (Windows-safe name, trimmed to 80 chars); unchanged root when the project is not a series episode or when the
  chosen folder already is that episode folder. `sync` and "Open folder" use it.
- `public` adds `folder` (the resolved path the files go to) and, when the project has no saved folder,
  `suggested_dir` = the root saved by another episode of the same series (latest updated).
- Step 1/7 panel: prefills `suggested_dir` when the path is empty and shows "Files go to: …\Ep 02 - …".
- Nothing is moved or deleted from the owner's folders: files already at the root stay; the next sync writes the
  episode subfolder.
- Tests: subfolder for an episode, none for a free project, no double nesting, suggestion from a sibling, open uses it.

## Acceptance Criteria
- [ ] Two episodes of a series with the same chosen folder write into separate `Ep NN - …` subfolders.
- [ ] Projects outside a series keep writing into the chosen folder.
- [ ] A new episode of the series is pre-filled with the series folder; the panel shows the real destination.
- [ ] Export tests pass.
