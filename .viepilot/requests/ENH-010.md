## Summary
After 16.4 removed repetition as a failure class (0.00% in 9/9 completed scripts), Gate B-7's two
script failures were both **global word-count overshoots**:
- B1 8-min run 1: 1,124 / 1,000, plus a 1.07% repeated-8-gram ratio, so a mixed failure;
- the B1 5-min sample: 703 / 625, word count only.

The pipeline repairs section length, but nothing repairs a total that ends up more than 10% over
target. A mixed failure is also excluded from Task 14.13's repetition repair by design, so it
dies without any repair attempt.

## Watch item (same gate)
The runner's `has_outro` heuristic missed two scripts at B-7 (0 at B-6):
- B1 run 4 is a false negative. Its real sign-off sits two lines before the last line.
- Owner run 1 genuinely ends on a call to action with no goodbye.

It is possible, not proven, that 16.4's rule 5 ("never repeat the same summary/takeaway
sentence") discourages a closing recap. Re-check at the next gate. If it recurs, consider
exempting the last section's wrap-up from rule 5, or checking the last 3 lines in the runner's
heuristic.
