## Summary
Thumbnails currently reuse 5 static background templates; the AI supplies only the text and
palette. D25 has two parts:
- **(A)** once Phase 18 is on, the cloud model writes the thumbnail text (no extra work);
- **(B)** a spike phase: a local image model (FLUX.1-schnell or SDXL-Turbo, chosen by the spike)
  generates a per-episode background. Pillow still renders the text, and the templates remain
  the fallback.

## Acceptance Criteria (proposal)
- [ ] The model is chosen by a measured spike: VRAM fit on 12 GB, time per image, licence, and
      quality.
- [ ] The step is behind a feature flag. On any failure it falls back to the existing templates.
- [ ] No model weights are bundled in the .exe.
- [ ] VRAM contention with the qwen fallback is handled (run only when Ollama has unloaded, or
      unload it explicitly).
- [ ] The owner compares generated vs template thumbnails on 5 real episodes and approves.

**D26 (2026-09-24):** no paid image APIs. Cartoon or modern 3D characters are invented per lesson topic. Candidates for the spike: Z-Image-Turbo, Qwen-Image GGUF, SDXL + a cartoon/3D LoRA. The headline is overlaid by Pillow by default. See the session file.
