## Summary
Today's video is a static background, the audio, and burned-in line-level subtitles (ffmpeg,
"Level 2"). [Remotion](https://github.com/remotion-dev/remotion) renders React compositions to
video (headless Chromium + FFmpeg).

**Licence:** free for "an individual" or "a for-profit organization with up to 3 employees".
The owner is solo, so free. A company licence is needed if the organisation exceeds 3 employees.

## Scope (D29: all four)
1. **Word-level karaoke captions** (`@remotion/captions`, `createTikTokStyleCaptions`). These
   need per-word timestamps. Edge TTS (already used) can emit WordBoundary events; today the app
   stores only line-level timing, so capturing and storing per-word timing is part of this work.
2. **Speaker indicator**: Alex/Maya name or avatar highlighted for the active line.
3. **Vocabulary/idiom pop-up cards** timed to the line that contains the item (from the existing
   Learning pack).
4. **Intro/outro + a chapter/progress bar + a thumbnail rendered as a Remotion still**. This feeds
   the thumbnail phase (ENH-012), where Remotion can typeset the headline over the AI-generated
   character art.

## Constraints / risks
- **Render time:** an 8-min 1080p30 video is about 14,400 frames. Rendering locally may take
  several to 10+ minutes (estimate). The spike must measure it on the owner's machine first.
- **Packaging:** Node.js + Chromium add roughly 150–300 MB to the .exe, and a second language
  (TypeScript/React) enters the repo. Consider a separate `video-renderer/` workspace invoked as a
  subprocess.
- **The ffmpeg path stays as the fallback:** any Remotion failure still produces today's video.
- The licence must be re-checked if the organisation grows beyond 3 employees.

## Acceptance Criteria (proposal)
- [ ] A spike measures render time and output quality for an 8-min episode on the owner's machine
      before full implementation.
- [ ] Per-word timestamps captured from Edge TTS and stored, with a migration.
- [ ] All four features are rendered and toggleable; the ffmpeg fallback is tested.
- [ ] Media gate: duration, A/V sync and codecs still pass, plus the owner's visual approval on
      real episodes.
