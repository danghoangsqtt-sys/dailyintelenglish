# BUG: Superseded render attempts are never deleted

## Meta
- **ID**: BUG-054
- **Type**: Bug
- **Status**: planned (Phase 79)
- **Priority**: medium
- **Created**: 2026-10-26
- **Reporter**: vp-audit

## Summary

Each episode, vertical or clip render writes to a new attempt folder; when the new one becomes current, the old folder (video ~150-250 MB plus a 7-8 MB verbose render log) is kept forever. Office Startup: 3 of 4 full videos (~540 MB) are unreferenced.

## Acceptance Criteria

- After a render is committed as current, the previous attempt folder of that output is removed (only attempt folders inside the project's video folder, never the current one, never on failure).
- Existing orphans are reported; deleting them waits for the owner.
