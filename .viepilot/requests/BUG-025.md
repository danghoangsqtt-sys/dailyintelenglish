## Summary
`_scene_plate()` in `app/services/video_renderer_remotion.py` catches every
`Exception` from both `get_scene_row()` and `resolve_library_content()` and returns
`None`. Expected missing scenes/files can use the existing fallback, but unexpected
SQLite or filesystem failures are treated the same way. `_build_sprite_props()`
then skips that line's scene without reporting the failure; `spriteBackground()`
can consequently show a different scene during the affected beat.

## Acceptance Criteria
- [ ] Keep expected missing-scene/file handling as a clear fallback.
- [ ] Surface or log unexpected lookup/read failures with the scene and project identifiers.
- [ ] Add regression tests proving operational errors are not silently treated as a missing plate.
