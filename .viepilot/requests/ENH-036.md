## Summary

1. **Diagram node IDs follow line position** (`frontend/static/js/explainer_editor.js:120`): editing the "nodes" textarea rebuilds nodes as `old[i]?.id`. Deleting or inserting a middle line shifts IDs, so the existing `edges` silently reconnect to the wrong nodes (they are only dropped when an ID disappears entirely).
2. **Stale guarded import** (`backend/library/explainer_service.py:279-287`): the comment says the checker "arrives in 49.6" and catches `ModuleNotFoundError` for `explainer_layout_service`, which has shipped. Import it directly and drop the fallback/comment.
3. **Desktop launcher silent timeout** (`backend/desktop_launcher.py:60-67`): if startup (migrations on a large DB) takes over 60 s, the browser never opens and the windowed EXE gives no feedback. Log or show a message on timeout.

## Acceptance criteria
- Node edits preserve IDs by label match (or edges are reset with a visible notice).
- Direct import in `_validate_geometry`; tests still pass.
- Launcher logs to `desktop.log` and/or opens the browser anyway after the timeout.
