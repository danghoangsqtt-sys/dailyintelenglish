## Resolution
Added `responseSchema` support to `_call_gemini` and `_generate_with_retry` in both `script_service.py` and `learning_service.py`, providing Pydantic JSON schemas (`_SCRIPT_LINES_ADAPTER.json_schema()`, `ScriptLineOut.model_json_schema()`, and `LearningPackOut.model_json_schema()`). Created `prompts/script/regenerate_line.txt` and added `render_regenerate_line_prompt` in `app/core/prompt_loader.py`. Preserved strict semantic validation and typed `AppError` exceptions on JSON decoding or schema errors. Added regression tests in `test_script_service.py` and `test_prompt_loader.py`.
