# ENH: Runner outro heuristic misses real sign-offs (gate measurement false negatives)

## Meta
- **ID**: ENH-014
- **Type**: Enhancement
- **Status**: open
- **Priority**: medium (must be decided **before** the next gate, so the goalposts don't move mid-gate)
- **Created**: 2026-09-26
- **Reporter**: PM (Gate B-11)

## Summary
`scripts/run_ai_operational_trial.py`'s `has_outro` checks a fixed marker list against the **last**
line only. At Gate B-11 it flagged 2/5 B1 scripts as having no outro. The PM read the real endings
("We truly appreciate you tuning in … look forward to seeing you in our next session"; "Thank you
for being part of our community … welcoming you back … next week"): both are real sign-offs.
Earlier false negatives: B-7 run 4, B-8 run 5.

## Acceptance Criteria (proposal)
- [ ] Widen the markers (tuning in / joining us / next session / welcoming you back / see you /
      until next time …) **or** base the gate decision on `has_outro_last3`, as an owner or PM
      decision recorded before the next gate.
- [ ] Unit tests using the real B-7, B-8 and B-11 endings.
