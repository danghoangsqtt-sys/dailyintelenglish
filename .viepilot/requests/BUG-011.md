## Summary
ScriptService and LearningContentService send Pydantic JSON Schema documents containing `$defs` and `$ref` via `generationConfig.responseSchema`. Google's REST contract reserves JSON Schema input for `responseJsonSchema`; `responseSchema` is the separate Schema/OpenAPI field. Both services also catch any `TypeError` and silently retry without a schema, defeating the mandatory output contract. Existing tests only assert that the incorrect key is present and do not cover LearningContentService's network payload.
