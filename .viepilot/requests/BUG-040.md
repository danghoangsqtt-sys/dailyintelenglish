## Summary
The 2026-10-15 full pytest run ended with 1,597 passed and 12 failed. All 12 failures were browser tests waiting 30 seconds for Playwright's `load` event during `page.goto()` or `wait_for_url()`, across four test modules and several local routes. Two representative failed tests passed when rerun alone (2/2 in 12.03 s), so the full-suite failure is intermittent and no product logic regression is yet confirmed. The pages link to `fonts.googleapis.com`; an external stylesheet delaying `load` is a plausible but unverified contributor.
