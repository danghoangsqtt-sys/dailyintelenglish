## Summary
Two real generic Activity Library illustrations visibly show a compass E/right arrow and W/left arrow, but both were saved as `walking outdoors`. Their aliases omit east/west, so the deterministic matcher finds no image for `go east`, `head east`, `go west`, or `head west`. The current vision prompt prioritizes general direction examples but has no cardinal-letter rule; Pydantic validates JSON shape and length without validating activity/alias meaning. Model confidence and analysis source appear only in the upload response and are not persisted for later review.
