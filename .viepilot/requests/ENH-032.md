## Summary
The manual PUT/sync routes and the automatic `sync_quietly` hook await folder checks and full file copies while holding `write_transaction`. That transaction uses one app-wide lock shared by reads and writes, so a large video copy or slow destination disk stalls unrelated dashboard/API database requests. Prepare a stable export plan under a short lock, copy outside it, and persist the sync result under another short lock.

## Details
- **Affected files**: `backend/api/export.py`, `backend/content/export_service.py`, `backend/db/transactions.py`
- **Evidence**: `export.py:37-39,56-58`; `export_service.py:197-223`; `transactions.py:read_transaction,write_transaction`

## Acceptance Criteria

- [x] A slow copy does not delay an unrelated database read; verified with a controlled concurrency test.
